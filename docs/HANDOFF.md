## v0.8 历史交接

## 从这里接手

1. 先阅读根目录 AGENTS.md、README.md、PROJECT.md、TASKS.md、DEVELOPMENT.md。
2. 使用 Godot 4.5.1 打开 `game/project.godot`，F5 运行。无音频时可检查菜单、切歌、自定义键；开始按钮会提示缺少文件。
3. 若要试玩已有谱面，请自行准备有权使用的录音，按 `game/assets/README.md` 导入。不同版本的录音可能错位，导入工具校验 SHA-256。
4. 在 TASKS.md 认领具体任务，说明负责文件与范围，再开始修改。聊天不会自动同步，关键结论写回文档。

## 代码入口

| 文件 | 职责 |
| --- | --- |
| game/main.gd | 菜单、切歌、播放、渲染、触控与键盘事件 |
| game/rhythm_session.gd | 判定流程、长按、连打、计分和输入源管理 |

| game/key_bindings.gd | 改键、冲突检查与配置 |

| game/chart*.json / song*.json | 人是猫两套谱面及元数据 |
| game/songs/ | 其他三首各自谱面和元数据 |
| game/tests/ | 判定、长按、多指、空击、歌单与流程测试 |
| tools/ | 本地音频导入和测试入口 |

## 已实现的约束

- 默认 J 地面、F 空中，支持主/备用键；空击完全忽略。
- 长按期间可操作另一轨，同轨不能同时放持续音符和单点；松手容差、暂停后续按等见 game/README.md。
- 歌曲原速、完整时长；人是猫按用户确认使用约 148 BPM，其余为本地录音拟合值，并非官方标注。
- 只共享项目结论和源文件，不上传聊天原文、本机路径、账号凭据或未授权商业歌曲。

## 建议接下来的任务（待认领）

- 谱面：先选一段短片段，明确跟随的声部并带声音逐拍对照，再测试连续击打、换轨、长按尾部；先验收片段，再扩展全曲。
- 安卓：配置导出环境，产出调试 APK，在手机上检查触控、音画时差与字体。
- 工程拆分：若拆 main.gd，先约定负责范围，避免双方同时改菜单与输入核心。
- 素材：确认可共享音频授权或加入原创测试曲。仓库没有商业 MP3，谱面自动模拟不等于实际听感验收。

本次导入保留八组既有测试，不将谱面质量描述为已经验证。原分析脚本与大体积临时音频未纳入运行工程；后续如需自动生成工具，应另立任务并使用可复现的相对路径。
