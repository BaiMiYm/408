# 本机账号与谱面创作

## 开始使用

1. 主菜单点击“设置 / 创作”。输入昵称，点击“创建并登录”；已有账号可在列表中选择并登录。
2. 点击“谱面创作 / 我的作品”，再点“新建谱面”。
3. 导入 MP3 / OGG 主音乐，填写曲名、作者、BPM 与起拍偏移；可选导入 PNG / JPG / WEBP 封面。
4. 时间轴上方为空中，下方为地面。选点按、长按或连打工具，再点击轨道放置。长按和连打使用“持续(拍)”设置长度，连打使用“连打数”设置击打次数。
5. 时间轴每八拍划为一个编辑段，显示段界和当前段编号。通过前后八拍、定位秒数、点击上方时间标尺或进度条浏览全曲；标尺定位不会添加音符。吸附支持一拍、半拍、四分之一拍、八分之一拍。BPM 与偏移只改变网格，已有音符的实际时间保持不变。
6. 点击已有音符选中，Ctrl+点击可多选；拖动头部移动或换轨，拖动持续音符尾部调整时长。选中后修改工具类型、持续拍数和连打数，再点“应用”。无效移动或粘贴会整体拒绝，保留原音符。
7. 用删除工具、右键或 Delete 删除。撤销/重做保留当前页最近 100 次音符操作。“播放 / 空格”从播放线处开始，空格原位暂停，再按继续；失去窗口焦点也会暂停。暂停位置保持可见，不退回起点。
8. 点击“保存”，再点“试玩”。保存的作品也会出现在当前账号的游戏歌单中，标为“自制”。之后可以从我的作品重新编辑。

## 快捷键与反复制作

| 操作 | 按键或入口 |
| --- | --- |
| 原位播放 / 暂停 | 空格；输入框编辑文字时不触发 |
| 回到当前八拍段起点 | R；保持播放或暂停状态 |
| 八拍循环 | “循环：开/关”，反复播放开启时光标所在段 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y，也支持 Ctrl+Shift+Z 重做 |
| 复制 / 粘贴 | Ctrl+C / Ctrl+V；有选中则复制选中音符，否则复制当前八拍段，粘贴到播放线处 |
| 复制整个段到下一段 | “复制段”；目标重叠或越界时不写入 |
| 删除选中 / 保存 | Delete / Ctrl+S |
| 节拍器、一拍预备、波形、录谱开关 | “更多工具” |
| 实时录点按 | 开启录谱并播放后，J 记录地面、F 记录空中；按当前吸附精度对齐。暂停和按键自动重复不会录入 |

八拍段从起拍偏移对应的网格计算；开头、结尾不足八拍的可播放部分会截断在音乐边界。R 使用当前播放线所在段，循环固定在开启时的段；主动定位会切换循环段。编辑改变 BPM/偏移后同步更新段界。

“更多工具”可开启一拍预备声，给手离开播放按钮留出时间；空格可取消预备。节拍器每拍发声、八拍起点使用高音提示。J/F 实时录制先铺点按骨架，长按和连打再通过选中“应用”调整。

波形从实际录音解码，分帧生成当前八拍视窗，首次显示会逐步补齐；暂停时也可查看。使用 Godot 自带 [AudioStreamPlayback.mix_audio](https://docs.godotengine.org/en/4.5/classes/class_audiostreamplayback.html#class-audiostreamplayback-method-mix-audio)，不依赖 FFmpeg 或网络。

“试听 20 秒”预听当前位置起的最多 20 秒，不生成独立 Demo 文件；启用八拍循环时优先循环当前段。

## 保存与账号

这是无需密码的本机身份切换，用于区分作品归属；不提供联网认证、文件加密或跨设备同步。账号列表、音乐副本、封面与谱面存在 Godot 的 `user://creator` 中。退出账号会从歌单隐藏该账号的作品，重新登录后恢复。

本次会话试玩启动器将用户目录定向至项目忽略目录 `.local/play-runtime/Godot/app_userdata/Neon Paws/`。直接从 Godot 编辑器运行时使用其标准用户目录，两者不会自动同步；备份时应整体复制对应的 `creator` 文件夹。测试使用独立随机目录，不修改试玩账号。

保存操作检查曲名、录音有效性、BPM 范围、同轨重叠、持续长度和音乐边界；保存项目 JSON 使用临时文件完成后替换。放弃编辑不会覆盖已保存的音乐副本；未保存导入可能留下未引用素材，暂不自动清理。

未保存的修改在返回或关闭创作窗口时会提示确认；异常退出仍可能丢失未保存操作。导入封面/音乐后会重新构建编辑页，当前音符保留，但该页撤销记录会重置。

## 当前范围与验证

本版支持主音乐、封面、本地时间轴编辑、实际波形与试玩。参考图中的背景视频、裁剪封面、自动节奏分析和独立试听文件导出尚未实现。2026-10-22 已导出 APK 与 Windows 独立运行包，安卓文件选择器、软键盘和触控体验仍需真机验收；见 RELEASE.md。

`creator_test.gd` 验证本机账号、保存重开与自制曲播放；`creator_editing_test.gd` 验证实际暂停/继续、R 与循环、一拍预备、文本焦点保护、标尺、拖动/拉尾/碰撞回滚、类型修改、复制粘贴、撤销重做、实时录谱与非零解码波形。测试入口为根目录 `tools/test.ps1`；当前十一组检查全部通过。

## 演奏前准备

点击游戏“开始演奏”、按 Enter、重玩或从工坊试玩时，会先显示约三秒的准备过场及两轨实际按键。倒计时结束后才从零启动音乐和谱面。过场可用 Esc、返回按钮或安卓返回取消；切走窗口也会取消。工坊内的音乐预听继续使用自己的空格暂停和可选一拍预备。当前全部十二组检查通过。
