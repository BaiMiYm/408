# 白发兽耳角色：Godot 动作测试

日期：2026-10-23。本轮仅修改源工程，没有重新导出 EXE、APK 或压缩包；此前独立运行包不会自动获得本次角色更新。

## 打开与操作

Godot 4.5.1 导入 `game/project.godot`，等待资源扫描后按 F5。主菜单新增“角色动作测试”，无需音乐即可试动作。也可以在编辑器打开 `game/character_lab.tscn`，按 F6 运行当前场景。

| 场景 | 按键 | 效果 |
| --- | --- | --- |
| 正常演奏 | 原自定义地面/空中键，默认 J / F | 地面攻击或起跳空中攻击；对应长按/连打音符使用持续动作 |
| 动作测试 | J / F | 地面 / 空中攻击 |
| 动作测试 | 按住 Q / E | 地面 / 空中长按；同时按住查看双轨持续分身 |
| 动作测试 | 连按 A / S | 地面 / 空中连打，快速交替查看打断与残影 |
| 动作测试 | 空格 / R / Esc | 暂停继续 / 重置角色 / 返回主菜单 |

测试场景底部也有鼠标/触控按钮。失焦会清理按住状态；测试页不运行歌曲判定、分数或生命值。正常演奏的空击仍不惩罚，但会播放攻击动作。

## 接入内容

- 使用用户动画 ZIP 中五张图集与 animation.json，原像素及透明度未重绘。每组八帧，单帧448×544，4×2图集，脚底锚点(224,496)。
- `whitecat_runner.gd` 独立管理帧时长、动作与升降。跑步670ms、地面攻击330ms、空中攻击520ms、连打320ms；新攻击立即切换，不等待收招完成。
- 空中攻击带快速上升与回落，落地有轻微压缩与尘线；短暂残影表现快速换轨，双轨持续显示第二个角色影像。
- 长按使用0/1进入、2–5循环、6/7退出，不把一次攻击无限拉长。连打交替起始姿态；挥击弧和命中星芒是独立代码特效。
- 动画命中停顿只影响角色帧推进，不修改音频位置、谱面时间、判定窗口或下一次输入。暂停时角色也暂停，重玩重置动作。
- 不改既有歌曲、谱面与改键；仅把旧几何猫咪绘制替换为图集动画，并将路线标签移到角色左侧以免遮挡。

## 验证与局限

十二组既有 Godot 回归检查通过；新增 whitecat_test 通过图集尺寸、帧时长、攻击打断、升降/落地、双轨长按循环/退出、连打变化、空击计分隔离、暂停/重玩及测试页失焦清理。

实际 OpenGL 画面检查地面攻击、空中攻击、双轨持续与独立测试页，截图在忽略目录 `.local/whitecat-review/`。没有声称真人全曲操作或与原作逐帧一致。

素材包没有独立起跳、落地、受击和死亡序列；本轮使用空中攻击姿态加位置/缩放完成升降与落地反馈，不冒充补齐了这些原画。素材自身的帧间服饰/配件变化仍存在。后续如需更精细的起跳、落地和攻击命中姿态，可再精修美术；本轮没有重新生成图片。
