# 两人协作指南

## 首次加入

1. 仓库所有者创建 GitHub 私有仓库并上传本项目。
2. 所有者在仓库 Settings → Collaborators 中邀请好友。
3. 好友接受邀请，将仓库克隆到自己的电脑。
4. 好友用自己的 GPT/Codex 打开克隆后的文件夹。
5. 双方都让 GPT 先读项目文档，再认领任务。

共同仓库：https://github.com/BaiMiYm/408 （私有）。好友接受邀请后可执行：

```powershell
git clone https://github.com/BaiMiYm/408.git
```

## 每次开发

1. 检查本地未提交改动；处理后拉取共同仓库的最新版本。
2. 查看任务表，与对方约定各自负责的功能或文件。
3. 为本次功能创建独立分支，例如 codex/note-input。
4. 开发、验证，并更新任务表和开发记录。
5. 提交并推送分支，在 GitHub 创建 Pull Request，检查后合并。
6. 另一位成员拉取合并结果，再开始后续工作。

拉取、提交和推送是版本同步，不会像共同文档那样逐字实时更新。
有未提交改动时不要直接重置或覆盖，先让 GPT 检查处理方案。

## 给好友的开场提示词

> 我正在和朋友共同开发这个音游。请先阅读根目录 AGENTS.md、README.md 及 docs 下的项目说明、任务列表和开发记录。概括当前进度和待定事项，再根据我指定的任务开展工作。开始前检查 Git 状态，保留他人的改动，完成后更新任务与开发记录。

## 聊天与素材同步

- 双方 GPT 的聊天历史各自独立，仓库不会自动同步聊天。
- 将重要需求、决定和交接信息写进项目文档，再提交推送。
- 如果账户支持共享 ChatGPT 项目，可用它共同讨论；它与本地代码仓库仍需分别管理。
- 音乐、图片等素材需有使用权限。较大的素材后续再决定是否使用 Git LFS 或共享素材盘。
- 不要用网盘同时覆盖两人的整个工作目录或 .git 目录。
