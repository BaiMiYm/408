## 本曲选点与分组的依据

- 分析每首本地录音的低/中/高频起音，以及两个频段的持续和声轮廓。两频段不是隔离出来的两件乐器或人声，仍可能受到伴奏影响。
- 保留各曲已使用的 BPM、相位、完整原速音频与 SHA-256；人是猫仍按用户已确认的 148 BPM。
- 改正旧版筛选基线：不把大量没有音符的十六分格混进八分起音基线，否则几乎所有八分都容易被选中。
- 短组首先来自实际起音间隔；较长连续组再参考起音重音分成 2/3/4 音。普通和舒缓段删减整个弱组，不在强组中间随机挖洞。
- 相似音频短句且所选节奏完全相同时，才复用换轨手型；没有强行按所有固定八拍段落镜像。
- 长按从持续和声候选中选择起止，两轨独立检查。长按前后清理同路邻近单点，另一轨可点按或持续；没有为每首曲子强塞双长按。例如ロストワン本次没有选出合适的双轨交叠持续组合。
- 连打只替换少量有密集起音支持的候选，所需次数按本项目规则计算，不能称为复制了原作的判定。

这仍是音频特征与视频形态辅助的编排。没有完成真人逐拍听写、带声音同步视听验收或安卓真机手感验收；测试完美只验证理想输入可完成。

## 可复现工具

`tools/audio_features.py` 与 `tools/refine_charts_from_references.py` 使用 NumPy 和 FFmpeg。示例：

```powershell
python tools/refine_charts_from_references.py --ffmpeg '你的 ffmpeg.exe 完整路径'
```

需要已按 assets/README.md 导入匹配的本地音频。特征缓存、修订前基线、动作组审计位于忽略的 `.local/`；运行工具会重写现有五套谱面，手动编辑谱面后请先备份。Godot 正常运行不需要 Python 或 FFmpeg。
