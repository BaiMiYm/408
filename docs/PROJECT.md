## 已有原型（本次会话确认）

- 玩法：两条路线的跑酷式节奏击打；地面 / 空中，单点、长按、连打。
- 技术：Godot 4.5.1，GDScript，自绘界面；横屏，目标安卓 arm64。电脑可用键盘测试。
- 输入：默认 J 地面、F 空中，两路备用键与持久化自定义键；手机左右半屏双指触控。
- 功能：四曲切换，《人是猫》普通+ / 挑战两套，其他三曲各一套；暂停、结果、重玩、时差补偿。空击不扣分、不断连。
- 内容：v0.9 依据三段参考视频修订四曲五谱，具体计数见 game/CHART_NOTES.md。BPM、音频哈希与相位保存在各曲元数据中。
- 状态：已导出 v0.9.1 Windows 独立运行包与安卓 ARM64 APK；PC 启动及 APK 签名校验通过，安卓真机验收尚未完成。谱面仍需带声音试玩，不能把自动模拟当作听感验收。
- 音频：歌曲完整 MP3 仅在本地使用，不上传未确认共享授权的音乐或图片；共同仓库不包含这些录音。

- 已按 BaiMiYm 本次选择增加本机账号与本地谱面工坊：无需密码的本机身份、音乐/封面导入、双轨三类音符编辑、保存与试玩；不含云端登录或同步。说明见 CREATOR.md，安卓端尚待真机验证。

- 2026-10-26 按 BaiMiYm 提供PSD替换本地游玩界面为公园美术、持棒角色、头像、血条和歌曲进度；用户明确要求零血立即失败。当前数值100血、MISS扣10，单姿态人物用变换衔接；见 PSD_GAME_UI.md。旧安装包未更新，仍待试玩与真机验收。
