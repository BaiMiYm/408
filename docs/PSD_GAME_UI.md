# PSD 公园游玩界面

日期：2026-10-26。依据用户提供的《未命名作品.psd》替换正常演奏界面；用户同时确认血量耗尽应立即结束并失败结算。

## 本轮效果

- 使用 PSD 的公园、云、沙地、水波、黑白判定圈、头像、蓝色血条、黄白条纹进度、金色箭头、蓝色返回形按钮和 COMBO 素材。
- 原稿2636×1870适配游戏1280×720横屏。背景按原堆叠与正片叠底合成；头像、按钮、判定圈与人物分别导出，动态数据由游戏绘制，不把示意数字487写死。
- 两条路线位于Y=456/334，判定横坐标仍为310；音符时间、BPM和判定窗口不变。左右半屏触控和自定义地面/空中键保持，底部大触控框改为较小文字提示，空击仍不扣血或断连。
- 顶部条纹与箭头、血条下方的细蓝条均显示实际歌曲进度。暂停不推进，失败停在当时位置，正常完成到100%，时间显示来自当前曲目完整时长。
- 右上 PSD 返回形按钮先打开暂停菜单，避免一次点击就丢失当前演奏；Esc行为不变。

## 血量与失败

当前测试数值：满血100，每个判定为MISS的对象扣10。点按漏击、长按提前松开、连打未完成均按一个对象扣一次；其他判定不扣血，不自动回血。数值常量位于 main.gd 的 MAX_HEALTH、MISS_DAMAGE。

血量降至30%及以下时描红提示，扣血尾迹短暂缓动。零血立即停止音乐与判定并进入“演奏失败”，未到达的音符不再批量补成MISS；失败准确率以实际已判定对象为分母，并注明判定数量。重玩恢复满血及正常三秒准备过场。

## 人物与素材范围

正常游玩改用PSD中的持棒角色，头像与人物一致。原稿只有一张人物姿态，因此通过原立绘的位移、旋转、轻微缩放和独立挥击特效衔接地面/空中攻击、长按、连打及分身；没有生成或声称已经画好该人物的跑步/攻击序列帧。

此前白发兽耳角色的原图集和独立动作测试场景保留，作为旧素材动作测试；不将其头像错配到本轮公园界面。
