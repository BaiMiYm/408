# 喵斯快跑：游戏内人物序列帧分析

日期：2026-10-23。任务 026，负责人：当前会话 Codex，BaiMiYm 发起。

分析对象是用户提供的三段实录中的玩家角色。这里的“帧”首先指录像解码帧；文中的动作分段是视觉分析，不代表已取得原作精灵图集、动画配置或输入日志。本轮仅分析与整理参考，没有修改游戏逻辑或确定本项目美术需求。

## 1. 主要结论

画面中的流畅感来自几项共同作用：清楚的关键姿态、姿态停留时间的差别、角色在上下轨之间的快速移动，以及独立变化的挥击弧、星爆、尘土和残影。只数整张画面有多少次变化，会高估人物本体的原画数量。

三段视频也显示，同一种玩法可以采用不同的角色动作：人形角色有腿部交替和武器挥击；小动物角色更强调拉长、压扁、翻转。双轨并行操作时，既出现上下两个同形轮廓，也出现单个身体在两圈之间转身，不能把一种皮肤的表现推广到所有人物。

## 3. 动作逐项拆解

### 跑步：稳定的循环底层

- C 3.000–4.111 秒：前腿伸出、收腿经过身体、另一条腿展开，身体有小幅上下起伏。头部朝向和面部识别保持稳定，主要变化集中在腿、重心和小幅摆动。
- C 的 n81（3.000 秒）与 n99（3.667 秒）、n84（3.111 秒）与 n102（3.778 秒），呈现相近的左右腿关系。可见完整循环约 **0.67 秒**，半步约 0.33 秒。数值只对应这一段录像。
- A 11.000–12.179 秒：身体较低，前后肢伸展与收拢，尾巴和身体随步态变化。B 4.333 秒以后：跑姿带明显前倾，长发拖在后方。
- 进入稳定游戏位置后，角色主要在画面左侧跑动，场景向左滚动；开场入场、攻击和换轨期间仍有位置变化。不能把场景滚动算成人物跑步帧。

### 地面攻击：一次短促动作，而非长时间蓄力

最干净的样本是 C 的第一个地面目标，前后都有可见跑步：

| 原生录像帧 | 时间 | 可见阶段 |
| --- | ---: | --- |
| n188 | 6.963 秒 | 仍在跑步，目标接近 |
| n189 | 7.000 秒 | 武器向前伸出，同时出现碰撞星爆 |
| n190–193 | 7.037–7.148 秒 | 武器转为斜向，白色挥击弧展开后缩小 |
| n194–197 | 7.185–7.296 秒 | 武器继续下摆、身体收招 |
| n198 | 7.333 秒 | 恢复跑姿，得分与星光仍存在 |

因此这次完整可见攻击约 **0.33 秒**；起止边界各有约一录像帧的不确定性。录像中没有可单独确认的长蓄力阶段，也不能据此声称输入延迟为零。

C 19.815–20.963 秒还能看到不同方向的挥击接续，但该段多次攻击相邻，不适合当作一个完整动作来计时。普通攻击的“几张原画”与连击中的“几次姿态切换”也不是同一个数量。

### 上下轨切换：身体轨迹与攻击姿态协同

C 26.407–26.963 秒：人物从下方上挑，移到上轨挥击，再向下转向，接下轨攻击并伴随尘土。武器方向随攻击方向变化，不只是把同一张站姿上下搬动。

截图中角色位置、武器倾角、挥击弧和尘土各有不同的变化节奏。适合把它理解为“角色移动 + 身体动作 + 特效”的组合；这是一种表现层分析，不是对原作内部程序结构的确认。

### 长按：切换到可以持续的姿态

- C 8.667 秒从普通挥击切成坐在游泳圈上的持续姿态；8.815–9.000 秒身体相对稳定，前方光圈、星形和音符持续变化。9.074 秒已切到上轨持续。
- B 90.444–91.000 秒：上轨角色维持在蓝色光圈前，下轨同时出现同形角色及青色残影，配合粉色目标攻击。可以描述为“分身／残影式双轨表现”，无法仅凭录像确定用了几个内部角色实例。
- A 65.000–65.786 秒：上下光圈之间主要是一个竖直的身体，背面、侧面、正面反复切换。双轨光圈并不等于两个角色身体。

由此，长按更适合按“进入 → 持续循环 → 退出”拆解，而非把一次普通攻击简单减速、拉长。本轮未逐一确定所有角色退出长按的完整动作边界。

### 连打：短动作切换与重复反馈

B 68.370–69.037 秒附近，HITS 数字逐步增加，身体在几种短促攻击姿态之间切换，伴随连续星爆；69.148 秒已回到跑步。

可确认的是连续击打的视觉反馈。HITS 是游戏计数，不是原画帧数；录像也不足以确定每个输入与每次动画重启的一一关系。不要为了让一个长动画播放完才允许下一次攻击。

### 小动物的形变：夸张幅度本身构成动作

A 12.321–12.643 秒是清楚的形变样本：跃起 → 空中翻转/蜷身 → 向下拉成细长形 → 着地压扁 → 回弹。12.464 秒到 12.500 秒之间，轮廓从纵向拉长转为横向压扁。

这一段同时有音符与“200”收集反馈，不能把每一次形变都标为普通攻击。它证明的是角色形变语言，不是某个攻击状态的完整时长。对体型紧凑的原创角色，这类轮廓变化尤其值得参考。

### 尚未确认的动作

本轮未找到足够清楚、可连贯核验的受击、死亡完整序列。场景变暗、屏幕闪光、分身和收集星光不能直接当作受伤证据。结算立绘也没有纳入游戏内动作循环统计。

## 4. 人物本体与特效要分开读

| 可见部分 | 典型证据 | 对分析的意义 |
| --- | --- | --- |
| 身体、头发、武器 | C 跑步和首次攻击 | 判断关键姿态与收招边界 |
| 位置与形变 | C 上下轨切换、A 拉伸落地 | 判断运动轨迹、重心和轮廓变化 |
| 挥击弧、碰撞星爆、尘土 | C 7 秒、26 秒 | 增强方向和力度，变化次数不能算进身体原画数 |
| 长按圈、残影 | A 65 秒、B 90 秒 | 表达持续状态和双轨并行 |
| PERFECT、200、HITS | C 7 秒、B 68 秒 | 判定/计数反馈，不是角色动作素材 |
| 紫色浮游小角色 | 三段均可见 | 与主要玩家身体分别观察，不混为跳跃或分身帧 |

## 5. 给本项目的制作建议（尚未确定的需求）

如果后续制作自己的序列帧，可以先做一名角色的动作样片，确认轮廓和衔接后再扩展角色数量。以下是建议的首轮绘制预算，**不是原作帧数统计**：

| 动作 | 建议先画的独立姿态/图像数 | 要检查的重点 |
| --- | ---: | --- |
| 跑步 | 6–8 张 | 前后腿交替、首尾接得上、落脚位置稳定 |
| 地面攻击 | 每种 4–6 张 | 出手明确、击中姿态有停留、收招可衔接下一击 |
| 空中攻击 | 每种 4–6 张 | 上挑与下落方向清楚，不能只复用地面姿态平移 |
| 长按 | 进入 1–2 + 循环 3–4 + 退出 1–2 张 | 持续多久都不必拉长一次性动画 |
| 连打 | 2–4 个短攻击姿态 | 重复时有变化，输入密集也能及时反馈 |
| 受击 | 后续单独设计 | 本次没有原视频证据，不作原作复现 |

时间分配比把每张图平均播放更重要。可以用本次 C 的约 0.67 秒跑步循环、约 0.33 秒地面攻击作为初始样片的比较对象，再按原创角色体型和实际游戏节奏调整。

建议人物图、挥击弧、碰撞星爆、尘土分别制作；画布和脚底/身体中心的对齐点保持一致。节奏判定由歌曲时间和输入决定，人物动画只负责表现；新攻击或换轨到来时应能衔接或打断当前收招。这些是本项目可采用的实现建议，并非已经确认原作使用的技术方案。
