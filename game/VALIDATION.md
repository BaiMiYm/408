# v0.9 验证记录

日期：2026-10-21；Godot 4.5.1，Windows。范围为参考三段视频后的四曲五谱修订；判定、输入、选歌与音频文件本轮未改。

## 通过的检查

- judge_test：普通+全谱、判定边界、148 BPM 网格、歌曲边界与同轨间隔。
- flow_test：播放、触控全曲、暂停/恢复、结果、重玩和返回菜单。
- key_bindings_test：默认 J 地面 / F 空中、自定义键、冲突与持久化、完整键盘输入。
- sustain_test：持续音起止、尾部容差、输入源接力、暂停续按、连打计数、跨轨操作。
- sustain_input_test：双指、取消触控、失焦续按与拖动归属。
- empty_input_test：空击不扣分、不断连、不提示，真实漏击仍结算。
- challenge_test：普通+与挑战分别用键盘和两路触控理想输入完成全曲，均全部完美；快速同轨对、网格、双押、持续占用及难度切换通过。
- playlist_test：其他三曲分别用键盘和两路触控完成全曲，683 / 1019 / 430 个对象，理想输入全部完美；元数据、音频哈希/时长、网格、歌单循环、重玩与菜单通过。
- 数据审计：五套谱面均相对 v0.8 变化，四个 MP3 的 SHA-256 与原元数据一致；时长、BPM、相位保留。
- 生成工具复现：用修订前基线和同一音频特征再次生成，五套谱面及五份元数据逐字节一致。
- 实际渲染：五个难度菜单、四曲持续段截图已生成；检查人是猫两个菜单、四曲持续条，未见布局遮挡。人是猫、海馬成長痛与 Never More 的截图中两轨长按均实际处于 active 状态，ロストワン截图为单轨长按配另一轨点按。

测试日志：忽略目录 .local/runtime/；画面检查：.local/v09-visual/。参考证据和建议试听片段见根目录 docs/VIDEO_CHART_REVIEW.md。

- 发布检查：59 文件源码 ZIP 完整性、四曲五谱及版本号通过；无商业音频、参考录像、截图、缓存或日志。由该 ZIP 解压的新鲜副本运行 missing_audio_test，通过四曲无音频启动检查。
