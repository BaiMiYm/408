2026-10-19，Windows，Godot 4.5.1。四曲五谱全量重编。对象计数以各歌曲元数据为准。

## 已通过

- judge_test：判定边界、普通+全谱、148 BPM 网格、时序、歌曲边界、同轨间隔。
- flow_test：音频时长、不循环、全曲触控输入、暂停、结果、重玩与返回菜单。
- key_bindings_test：J 地面 / F 空中、自定义键、冲突检测、持久化、损坏配置回退、按键重复及全曲键盘输入。
- sustain_test：长按完成、提前松手与尾部容差、多源接力、暂停恢复、连打计数、长按键不能代替连打、另一轨操作。
- sustain_input_test：双指长按与另一轨点按、触控取消、焦点丢失与续按、拖动的路线归属。
- empty_input_test：空击不扣分、不断连、不发提示；真实漏击仍计入结果。
- challenge_test：普通+ / 挑战元数据、十六分网格、快速同轨间隔、双押、长按占用；两难度分别用键盘与双触控完成全曲理想输入；重玩和难度切换。已将旧版固定对象数断言改为读取元数据，并保留挑战比普通+密集的检查。
- playlist_test：其他三曲分别由键盘与双触控完成全曲理想输入；618 / 991 / 380 个对象，全部完美；音频时长/哈希、各曲网格、类型/双押/总按下次数、排序和持续音符占用；切歌首尾循环、难度记忆、单谱面控制、重玩、返回菜单、演奏中不能切歌。
- 实际渲染：四曲菜单、四曲演奏页、长按及连打显示。标题、对象数、曲目与控件未见裁切或重叠。
- 打包脚本检查 ZIP 完整性、清单与版本、五套谱面相对 v0.7 全部变化，四个 MP3 与 v0.7 逐字节相同。
