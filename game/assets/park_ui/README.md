# 用户 PSD 界面素材

来源：《未命名作品.psd》，原尺寸2636×1870。原文件保留在用户提供的位置，没有覆盖。

13张PNG为图层裁切或按PSD堆叠/正片叠底合成的结果，没有生成式重绘。source_manifest.json记录原文件SHA256、图层索引及源裁切区域；background.png为不含UI与人物的背景合成，其他素材分别供动态HUD和人物绘制使用。scenery/ground/water另留作分层参考，当前绘制使用完整背景以保留准确堆叠。

头像裁自PSD已有合成预览，以保留其剪贴关系。人物合成黑外轮廓、白描边与彩色层；原稿只有一个姿态。COMBO标签沿用原稿，数字由实际连击数绘制。参考 docs/PSD_GAME_UI.md。
