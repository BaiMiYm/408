# 本地音频

本目录不提交商业歌曲音频。已有谱面使用原录音的完整版本，BPM、相位和时长见歌曲元数据。

| 歌曲 | 本地文件名 | BPM（约） |
| --- | --- | --- |
| 人是猫 | ren_shi_mao.mp3 | 148 |
| 海馬成長痛 × Mass Destruction | kaiba_mass.mp3 | 140 |
| ロストワンの号哭 | lost_one.mp3 | 162 |
| Never More | never_more.mp3 | 93 |

仅导入自己有权使用的音频。将以上文件放进本目录，或运行根目录的 tools/import_audio.ps1。工具按歌曲元数据中的 SHA-256 检查录音版本；不同剪辑/前置静音可能使谱面错位。

没有音频也能打开菜单、切歌和改键；对应曲目的开始按钮会提示先导入。本地 MP3 尚未生成导入缓存时，游戏可直接读取原文件；复制后请重启游戏。
